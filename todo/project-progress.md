## 진행 규칙

- 한 번에 하나의 TODO만 진행한다.
- 구현 직후 관련 동작을 검증한다.
- 완료한 TODO에는 실제 검증 결과를 남긴다.
- 작업 중 발견한 추가 요구사항은 임의로 섞지 않고 이 파일에 새 TODO로 추가한다.
- Git 연동 기능은 읽기 전용 조회부터 구현한 뒤 명령 실행 기능으로 확장한다.
